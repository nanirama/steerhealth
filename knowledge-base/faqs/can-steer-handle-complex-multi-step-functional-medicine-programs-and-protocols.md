# Can Steer handle complex, multi-step Functional Medicine programs and protocols?

Yes. Steer lets you build structured programs (e.g., 3/6/12-month protocols) with visits, labs, tasks, supplements, and education mapped over time. You can standardize programs across providers while still personalizing for each patient’s plan.
